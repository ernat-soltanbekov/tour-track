## Нагрузка

`go run ./cmd/stress -requests 5000 -concurrency 32` против собственного localhost-процесса с прогретым кэшем:

```json
{
  "requests": 5000,
  "concurrency": 32,
  "failures": 0,
  "elapsedMs": 319,
  "p50Ms": 0.620208,
  "p95Ms": 8.4745,
  "maxMs": 34.035542
}
```

Это локальные цифры, не прогноз производительности бесплатного хостинга и не проверка отказа ОС. Смесь включает корректные 400 и 404, которые сравниваются с ожидаемыми статусами. Дополнительно integration-тест делает 1280 HTTP-запросов от 32 клиентов. Отдельный тест проверяет отказ с 503 при исчерпании лимита обработчиков; ещё один — 100 одновременных холодных запросов к одному кэшу.
