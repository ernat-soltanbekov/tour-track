# Матрица аудита

Предмет: `tour-track`. Основание — предоставленное ТЗ и его раздел AUDIT. Это карта проверок, не гарантия решения конкретного аудитора.

## Обязательные требования

| Требование | Реализация и проверка |
| --- | --- |
| `go.mod`, `main.go`, `internal/activity/classifier.go` и тесты | Структура в корне репозитория; `go test ./...` |
| Go, только стандартные пакеты | В `go.mod` нет `require`; CI проверяет `go list -deps` |
| Данные artists | Имя, фото, состав, год и альбом на HTML/JSON-страницах |
| Данные locations | Raw-список на странице и уникальные страны в счёте |
| Данные dates | Полный счётчик концертов, Rising Star, список дат без площадки |
| Данные relation | Таблица площадок и связанных дат |
| Правильное соединение четырёх частей | `TestLoadAllFourAndAuditRecords`, `TestJoinUsesIDsNotArrayPositions` |
| Queen: 7 участников, включая написания ТЗ | `TestLoadAllFourAndAuditRecords`, `/artists/1` |
| Gorillaz: `26-03-2001` | Тот же тест, `/artists/39` |
| Travis Scott: перечисленные 10 локаций | Тот же тест, `/artists/30`; оговорка brazil/brasil ниже |
| Foo Fighters: 6 участников из ТЗ | Тот же тест, `/artists/51` |
| Событие клиент → сервер → ответ | GET-форма и асинхронный поиск; браузерная проверка в VERIFICATION |
| Корректные HTTP-методы | GET/HEAD, 405 с Allow для остальных; `TestRoutesAndHTTPMethods` |
| Все существующие страницы доступны | `TestAllArtistPagesAndBadges`: каталог + все 52 detail-страницы |
| Обработка 500 | `TestRecoveryReplacesPartialResponse`, `TestConcurrencyLimitAndResponseSize` |
| Ошибки источника | `TestClientFailures`, `TestClientTimeoutAndCancellation`, `TestUpstreamFailureAndStaleBanner` |
| Сохранение работоспособности после нагрузки | `TestConcurrentRealHTTPStress` и `cmd/stress` |
| Бейдж на каждой карточке и detail | Общий HTML-шаблон `badge`, тот же вывод в JS; тест всех страниц |
| Travis Scott → Established / Legendary | В снимке на 2026 год: 6 стран, 12 дат, 18 лет → 51 → Legendary |
| Мало/нет дат → формула, в том числе Emerging | Синтетические случаи нулевой активности и границ |
| Точная формула и границы | `TestScoreAndClassify`: 0, 10, 11, 25, 26, 40, 41, целочисленное деление и cap |
| Пример 5 / 8 / 30 → 40, Established | Именованный subtest `subject example` |
| Отдельный пакет и помощник формулы | Экспортируемые `activity.Score`, `activity.Classify` |
| Год на время запроса | `TestCountryAndRequestYear`, `TestRequestTimeReclassification` |
| Читаемый код, обработка ошибок, форматирование | Именованные слои, комментарии о причинах, `gofmt`, `go vet` |
| Тестовые файлы присутствуют и запускаются | `go test ./...`, GitHub Actions |

«Отсутствие 404 страниц» трактуется как отсутствие сломанных внутренних ссылок. Для несуществующего пути правильный HTTP-ответ — 404; маскировать его кодом 200 было бы ошибкой.

Требование про малое число концертов не отменяет формулу. Старый артист с двумя датами может оказаться Active за счёт стран и карьеры. В реальном историческом снимке может не быть ни одного Emerging; тесты на синтетических данных проверяют этот класс отдельно. Подменять реальные оценки ради красивого распределения нельзя.

## Дополнительные стресс-сценарии

- 100 одновременных промахов кэша → одна загрузка.
- 1280 реальных HTTP-запросов в integration-тесте, 32 параллельных клиента.
- 5000 смешанных запросов к запущенному приложению отдельной утилитой.
- 500/429/redirect, некорректный JSON, лишний JSON, null, пустой набор, превышение 4 МиБ.
- Неизвестные и повторяющиеся ID, отсутствие частей, несуществующие даты и локации.
- Ожидание API, отмена запроса, независимость общего обновления от отмены посетителя.
- Старый снимок, неудачное обновление, cooldown, истечение 24 часов, восстановление источника.
- Паника загрузчика и обработчика, частично записанный ответ, ответ свыше лимита.
- Некорректные параметры, очень длинный URL, попытка обхода путей статики, HTML-инъекция.
- Fuzz для целочисленных аргументов, дат, стран и query string; `-race` для гонок.

## Реальные расхождения источника

Снимок от 28 сентября 2026 года содержит `sao_paulo-brazil` у Travis Scott; в ТЗ написано `sao_paulo-brasil`. Raw-данные отображаются без подмены. В проверке списка и при подсчёте стран учитываются оба написания.

У Maroon 5, The Rolling Stones и Foo Fighters часть записей `dates` отсутствует в `relation`. Счётчик использует `dates`, а непривязанные даты выводятся отдельно с объяснением. Концерты не выдумываются и не удаляются для согласования источников.

Написания участников, включая `John Daecon` и `Doug Fogie`, сохранены согласно API и ТЗ, даже если исторически имя принято писать иначе.

## Собеседование

Пункты «может объяснить без кода», «считает пример сам» и «понимает собственную работу» проверяет человек. Автотесты этого не доказывают. Для подготовки есть ARCHITECTURE и разбор формулы прямо на страницах. Эти пункты не помечаются как автоматически пройденные.
